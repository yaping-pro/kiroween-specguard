# Product Steering: SpecGuard Crew Framework

## 1. Vision & Core Mission
SpecGuard Crew is a production-grade, reusable foundation template built for the AWS Kiroween 2026 hackathon (Skeleton Crew track). Its mission is to bridge the gap between AI generation and mathematical correctness by pairing agentic workflows with automated Property-Based Testing (PBT) and invariant enforcement.

## 2. Invariants & Non-Negotiables
- Every core domain mutation MUST maintain formal mathematical invariants verifiable across at least 1,000 randomized iterations.
- Code generated by Kiro or peer agents must conform to strict EARS (Easy Approach to Requirements Syntax) specifications.
- Dual application demonstrations must prove versatility across orthogonal domains:
  1. `app-1-necromancer-vault`: Deterministic cryptographic key-splitting and zero-knowledge reconstruction.
  2. `app-2-potions-exchange`: High-frequency multi-asset limit orderbook matching engine with conservation of value.
- Zero server dependencies: Must build cleanly into self-verifying standalone web applications that can run in any modern browser without remote backend dependencies.
